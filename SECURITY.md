# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

TokDash parses local files and session logs directly on your machine. We take local data privacy and security seriously:

1. **Zero Cloud Upload**: TokDash processes your AI tool session metrics entirely on your local machine. No session transcripts, prompts, or sensitive keys are transmitted to any remote servers.
2. **Reporting**: If you discover a security vulnerability (such as unintended credential exposure or sandbox bypass), please **do not** open a public issue.
3. **Contact**: Open a private vulnerability report via GitHub Security Advisories or contact the maintainer directly at [https://github.com/kamanager2012](https://github.com/kamanager2012).
4. **Response Time**: We aim to acknowledge reports within 48 hours and provide a patch or mitigation within 7 days.
